RCE через Eval-инъекцию в PHP

Что это такое? Remote Code Execution (RCE) — это уязвимость, позволяющая злоумышленнику выполнять произвольный код на сервере. В PHP это часто происходит через функцию eval(), которая выполняет строку как PHP-код. Злоумышленник может внедрить вредоносный код, например, через формы или URL, и сервер выполнит его.

Пример атаки: В файле index.php появляется строка вроде eval(base64_decode('...'));. Это позволяет запускать команды, красть данные или перенаправлять трафик (например, на казино).

Как защититься? Никогда не используйте eval() с пользовательским вводом. Проверяйте и фильтруйте данные. Для очистки: найдите вредоносный код с grep, удалите с sed.

Демо ниже: Посмотрите, как выглядит заражённый код, переключитесь на чистую версию и увидьте команды для удаления.
